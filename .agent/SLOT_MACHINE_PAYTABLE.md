## 🔒 Características de Seguridad

### Auditoría y Transparencia

Cada jugada guarda:
- **RNG Data**: Índices exactos generados `[reel1_idx, reel2_idx, reel3_idx]`
- **Result Reels**: Símbolos resultantes `["💎", "7️⃣", "⭐"]`
- **Bet Amount**: Cantidad apostada
- **Win Amount**: Cantidad ganada
- **Player ID**: Identificador del jugador
- **Game ID**: Identificador del juego
- **Timestamp**: Fecha y hora de la jugada

### Generación de Números Aleatorios (RNG)

```javascript
import { randomInt } from "crypto";
const index = randomInt(0, 32); // Criptográficamente seguro
```

Utiliza el módulo `crypto` de Node.js que es **criptográficamente seguro** y cumple con estándares de la industria.
